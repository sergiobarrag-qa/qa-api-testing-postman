## Propósito

Ejercicio colaborativo de QA enfocado en el diseño y ejecución de pruebas de API REST con Postman sobre JSONPlaceholder. El trabajo contempla intercambio de criterios, ejecución de solicitudes, revisión de respuestas y documentación conjunta de resultados.

## Alcance

- 46 casos principales sobre `posts`, `comments`, `albums`, `photos`, `todos` y `users`.
- 20 casos complementarios de carácter exploratorio.
- 66 solicitudes en total.

## Criterios de documentación

Los casos principales se reportan según las aserciones configuradas y los resultados observados. Los escenarios complementarios se registran como exploratorios cuando no existe un criterio de aceptación suficiente; una respuesta inesperada no se declara automáticamente como bug.

JSONPlaceholder es una API de demostración: las operaciones de escritura pueden simular respuestas y no garantizan persistencia.
